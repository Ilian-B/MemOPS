# Dossier sources

Nous déposons ici les textes de référence officiels nationaux (GDO, référentiels) au format PDF.

- Ce dossier n'est jamais publié dans le dépôt (voir `.gitignore`).
- Nous gardons le nom d'origine du fichier et ajoutons la version ou la date si elle n'y figure pas, par exemple : `GDO-ventilation-operationnelle-2018.pdf`.
- Lorsqu'un texte est mis à jour, nous conservons l'ancienne version le temps de revoir les questions qui en sont issues.
