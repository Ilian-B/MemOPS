# Signalements sur les textes sources

Nous consignons ici les ambiguïtés, contradictions ou coquilles relevées dans les textes de référence. Nous ne tranchons pas : ces points sont à soumettre à un formateur ou conseiller technique, et éventuellement à l'auteur du texte. Aucune question ne doit reposer sur un passage signalé tant qu'il n'est pas clarifié.
