# Révision pompiers

Application de quiz mobile (PWA) pour entretenir ses connaissances opérationnelles de sapeur-pompier et de secouriste, à partir des seuls textes de référence officiels.

> **Avertissement** : outil d'entraînement personnel. Ne remplace ni la formation, ni les textes officiels en vigueur.

## Principes

- Questions tirées exclusivement des GDO et référentiels nationaux, chacune avec sa source précise.
- Chaque proposition de réponse est vérifiée contre le texte avant publication.
- Révision par thème, mode aléatoire adapté à l'emploi, suivi de progression et répétition espacée.
- Fonctionne hors ligne, sans compte.
